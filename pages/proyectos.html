2026 · Bachelor's thesis · Computer Vision & AI

[Automated grazing assessment in kelp]

My Bachelor's thesis: a tool for UDC scientists that assesses damage and determines the origin of kelp samples through a Deep Learning pipeline combining detection (YOLO) and ordinal classification (CORAL-CNN) models. Supervised by [Manuel González Penedo] (head of [CITIC]).

Presented as an oral communication and published at the [9th XoveTIC Conference].

2026 · Hackathon · 2nd place

[HackUDC 2026 · G8keeper]

Password manager built as a Chrome extension with my team for Gradiant's security challenge, where we won second place. Zero-knowledge architecture: all encryption happens locally with the Web Crypto API (double AES-256-GCM, PBKDF2/HKDF-SHA-512, HMAC integrity checks), plus recovery codes, auto-lock and breached-password checks using k-anonymity.

[Devpost] [LinkedIn post]

  • TypeScript

Personal project · Homelab

[Personal server with Proxmox]

A MiniPC running Proxmox that I use every day as my personal server: media server for my films, photo backups with Immich, home automation with Home Assistant and personal finances with Actual Budget. Each service lives in its own virtual machine, and setting up storage across several drives (with backups so no photos get lost) was the hardest part. I shared the experience in a [talk at GPUL].
