2026 · Competición · 2º puesto

[HackUDC 2026 · G8keeper]

Gestor de contraseñas como extensión de Chrome, desarrollado en equipo para el reto de seguridad de Gradiant, donde quedamos en segundo puesto. Arquitectura zero-knowledge: todo el cifrado ocurre en local con la Web Crypto API (doble AES-256-GCM, PBKDF2/HKDF-SHA-512, HMAC de integridad), con códigos de recuperación, auto-bloqueo y comprobación de contraseñas filtradas mediante k-anonimato.

  • #TypeScript
  • #Criptografía
  • #Chrome Extension

Proyecto personal · Homelab

[Servidor personal con Proxmox]

Un MiniPC con Proxmox que uso a diario como servidor personal: media server para mis películas, copia de seguridad de fotos con Immich, domótica con Home Assistant y finanzas con Actual Budget. Cada servicio vive en su propia máquina virtual, y montar el almacenamiento entre varios discos (con backups para no perder las fotos) fue lo más difícil. Conté la experiencia en una [charla en GPUL].
