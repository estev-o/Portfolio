> International Master in Computer Vision (IMCV) · in progress

Fundamentals of Image Processing and Analysis

A levelling course for students coming from different backgrounds. We cover digital image fundamentals, colour perception, image enhancement and restoration, geometric transformations, edge detectors and template matching. In the labs I implemented, for example, connected-component labelling from scratch with NumPy.

Image Description and Modeling

How to describe the visual content of an image: transforms, filter banks and visual modelling for recognition. It combines hands-on notebooks with OpenCV and a research project with metrics that has to be defended.

Instrumentation and Processing for Biomedical Applications

How medical images are acquired (X-ray production) and how their quality is measured. The labs are Python notebooks with NumPy, Pillow and Matplotlib.

Fundamentals of Machine Learning for Computer Vision

Learning theory and probability as the formal basis of Machine Learning: problem types, model families and generalization. It ends with a free-topic ML project.

> Fourth year · Computing specialization

Computer Vision

The course that confirmed what I wanted to do. In the first assignment I implemented processing functions from scratch in Python: histogram adjustment and equalization, Gaussian and median filters, morphological operators, hit-or-miss and edge detectors (gradient, LoG and Canny). In the second I segmented images with region-based adaptive thresholding and evaluated the result pixel by pixel against the ground truth. I learned that documenting why each decision is made (and what failed) matters more than getting the best result.

Computer Graphics and Visualization

Two halves: OpenGL in C to understand the graphics pipeline (primitives, transformations, clipping, visible surfaces, lighting and shading) and Blender for modelling and animation. The final Blender project was the penguin animation you can find in [Projects].

Language Processing

How a compiler works on the inside: lexical analysis, parsing (LL, LR and precedence), semantic analysis and code optimization. In the labs I built an XML validator with Flex and Bison.

Programming Language Design

Type systems and object-oriented languages from a formal point of view. In the assignment we extended a lambda-calculus interpreter in OCaml, adding new constructs such as recursion.

Immersive, Interactive and Entertainment Environments

Video game programming: 3D engines, design patterns and game AI. I applied it in two team games, one in Pygame and one in Unity (see [Projects]).

Internship

Curricular internship in the Computer Vision department at ITG (see [Experience]).

Bachelor's Thesis

Deep Learning pipeline with YOLO and CORAL-CNN to assess grazing in kelp, published at XoveTIC 2026 (see [Projects]).

> Third year

Knowledge Representation and Automated Reasoning

We brought logic down to earth with lightweight ontologies and inference engines. It helped me describe real domains and automate conclusions without writing more rules than needed.

Intelligent Systems Development

We built agents and small expert systems. This is where I practised the most how to split decision logic and justify why an agent acts in a certain way.

Machine Learning

I built ML pipelines with Python and some Julia. What stuck with me most was data cleaning and how to document experiments so I wouldn't get lost among notebooks.

Theory of Computation

Back to automata, formal languages and complexity. I kept notes on the proofs we repeated the most so I can reuse them when designing languages or parsers.

Information Retrieval

We built simple search engines and I learned to evaluate rankings with clear metrics. I keep here the benchmarks I ran comparing BM25 with more modern variants.

Project Management

I practised planning, estimation and role assignment. I noted which dynamics helped us meet deadlines and which tools we actually used as a team.

Human-Computer Interaction

We did research with real users, rapid prototyping and UX testing. I apply the conclusions every time I lay something out so it can be understood without a manual.

Internet and Distributed Systems

I reviewed distributed architectures, fault tolerance and scaling patterns. I keep the diagrams I use as a starting point when thinking about distributed deployments.

Legislation and Computer Security

We covered the legal framework and data protection. I also learned good security practices on Linux.

Infrastructure Management

We focused on operations, deployments and monitoring. We saw how to manage servers and services efficiently.

> Second year

Algorithms

Consolidating complexity analysis and optimization techniques. We studied several classic algorithms and their implementations.

Computer Structure

How hardware works internally and the instruction pipeline.

Programming Paradigms

We used OCaml to explore functional and logic programming. It was key to understanding different approaches to problem solving.

Software Design

Patterns, architecture and collaborative work. It was the first time we used Java and object-oriented programming in depth.

Operating Systems

Resource management, concurrency and file systems. The labs were done in C.

Databases

Networks

Concurrency and Parallelism

Software Process

Agile methodologies and documentation. We also made mockups and UML diagrams.

Intelligent Systems

Classic AI, heuristics and simple agents. I learned basic concepts such as search (Dijkstra, A*...) and genetic algorithms.
